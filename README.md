# Student Project Tracking & Evaluation System - Beginner Version

## Technology
- Java 8
- VS Code
- ArrayList
- Scanner

## Features
1. Add Student
2. Add Project
3. Update Project Progress
4. Evaluate Project
5. View Projects

## Run in VS Code

Open the terminal inside this folder.

Compile:
javac Main.java Student.java Project.java

Run:
java Main

## Important
This beginner version is a console application. It does NOT create a webpage.

It is intentionally kept simple so beginners can understand and explain:
- Class and Object
- Constructor
- ArrayList
- Methods
- if-else
- switch
- for loop
- Scanner
